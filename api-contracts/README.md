# API Contracts

Published and partner-facing API specifications for Canary Retail
and adjacent GrowDirect LLC services.

## Planned content

- Canary Retail public API (REST, OpenAPI-specified) — the
  merchant-facing surface documented for integration partners.
- Canary Retail webhook contracts — event shapes Canary emits for
  partner consumption.
- MCP service contracts — the subset of internal MCP tools
  exposed to authorized external agents (principal-aware).

## Authoring rule

API contracts here are the ones GrowDirect commits to under
versioning. Internal, unstable, or in-flight APIs stay in the
Canary product repo, not here.
