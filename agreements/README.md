# Agreements

Standard template agreements GrowDirect LLC uses for engagement,
vendor, and distribution relationships.

## Planned content

- `nda-template.md` — mutual NDA used for pre-engagement
  discussions with retailers and partners.
- `vendor-partnership-template.md` — template for partnerships
  where GrowDirect either consumes a vendor's capability or
  integrates it into the Canary Retail platform.
- `license-standard.md` — standard license terms for method
  licensing (CATz methodology distributed outside GrowDirect
  delivery) and plugin distribution.
- `engagement-contract-template.md` — standard retainer agreement
  for a CATz engagement delivery.

## Authoring rule

Template text only. Actual executed agreements stay in legal
workflow / contract management, not in this vault.
