# CATz — Canary Agent Taskforce

**CATz** is GrowDirect LLC's methodology and delivery framework.
The name expands to **Canary Agent Taskforce** — a nod to what the
method actually is: a pack of trained, principal-aware AI agents
working alongside a human delivery lead, observing a retailer's
operation (watchful cats, not mice), translating what they see into
the canonical retail data model, and producing engagement-grade
deliverables at an SMB-feasible pace.

CATz is how GrowDirect designs, diagnoses, architects, and delivers
retail platform work. Externally-facing. Owned. Not a framework we
borrowed. Not a template we licensed. Our magic, our thought.

## What lives here

- **Method** — the engagement model, phases, workstreams, artifact
  templates, role playbooks.
- **CBM v2** — retail capability model with the four cells standard
  CBMs miss (Agent Strategy, Data Protection & Governance, PMO,
  Architecture Review Board).
- **About** — who GrowDirect is, founder bio, standards adoption,
  licenses.
- **Partnerships** — API partners, integration partners, standards
  bodies (ARTS, NRF, PCI SSC).
- **Agreements** — NDAs, vendor partnership templates, license
  standards.
- **API contracts** — published and partner-facing API specifications.
- **Bios** — founder and team bios written for external audiences.

## What does NOT live here

- Client-specific engagement material (prior or current)
- Internal tooling, code, or infrastructure
- Prior-company lineage or former-employer references
- Raw source material from any prior engagement

Those live in GrowDirect's internal Brain. This vault is sanitized,
owned, externally-shareable under NDA or acknowledgment.

## Authoring rules

1. **No client names.** Current or prior. Ever.
2. **No former-company references.** No IBM, no prior-employer lineage.
3. **All attribution to GrowDirect LLC.**
4. **Published-standard references are permitted** — ARTS, NRF, PCI,
   ISO, OWASP. Those are external standards, not proprietary lineage.
5. **Derived methodology is fine** — the frame may be informed by
   prior practice, but the expression here is GrowDirect's.
6. **Every file carries confidentiality frontmatter.** `classification:
   confidential`, `owner: GrowDirect LLC`.
